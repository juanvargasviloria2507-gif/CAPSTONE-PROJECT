Place your hero image here with the exact name: hero.jpeg
(or change the file extension/name in js/views/home.js,
on the line that says: <img src="assets/hero.jpeg" ...>)

Recommendations:
- Format: jpg/jpeg or png
- Vertical/portrait orientation, similar to the original design (e.g. 900x1100px)
- If you don't add an image, a fallback gradient will be shown with the
  "THE" / "FLARE" labels, with no errors on screen.
